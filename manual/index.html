02

五分钟，走一遍核心体验

建议第一次选择“和看山体验完整流程”，可以同时体验贡献与维护者审阅。

  1. 加入独立演示空间 · 约 30 秒

    右上角“加入我们” → “和看山体验完整流程”。如果已经是演示维护者，可以直接继续。

    两种演示身份有什么不同？
  2. 切换三个页面 · 约 1 分钟

    先读广场答案，再看“我的经历”的四份示例，最后打开“看山的小本子”。这时最容易看清个人输入和研究进展的区别。

  3. 写一份贡献 · 约 1 分钟

    在广场打开想补充的议题，点“我也经历过”，写下具体情境或填入演示经历。选公开身份 → 检查公开预览 → 勾选确认保存。“我的经历”的“写一份新贡献”也可以继续补充当前议题。

    查看公开预览与贡献管理
  4. 发出一条下一问，并回答它 · 约 1 分钟

    打开看山的下一问，核对正文与依据，预览后确认发出。进入广场的“下一问与后续回复”，在已送达的问题下输入一条具体回复。

    查看提问与回复的完整路径
  5. 审阅一份修订 · 约 1 分钟

    打开小本子中的待审修订，对比原文、建议和来源；勾选核对后采纳，再到版本历史看新旧答案。演示空间已经准备一份样例修订，也可以在来源中另选证据生成新建议。

    查看修订和版本说明
不是自动改写：提交经历、收到回复、生成建议，都不会直接替换当前公共答案。只有维护者核对并采纳修订，答案才发布新版本。这里的五分钟是熟悉入口的建议时间，可以随时停下来阅读。
03

答案广场

围绕一个议题，把当前答案、不同经历和仍待验证的条件放在一起。

A找到想继续看的问题

左侧分类与议题列表切换内容；右上放大镜搜索已有议题。点问题旁的星星关注，再用“我的关注”查看收藏的议题。

B每个条件，都可以追溯

“目前，我们知道”显示已确认答案。点击支持、反例或待验证标签，打开对应依据；“看看依据”展示全部来源。

C沿着未知继续探索

“看山的下一问”解释为什么要问；“经验里的不同侧面”展示贡献；“还想一起弄明白”保留尚不能下结论的条件。

版本号 / 答案成长记
查看历次已保存的答案与条件，进入修订建议。版本越多，时间线越完整。
下一问与后续回复
查看本站问题的送达状态和实际回复，继续补充经验或回答问题。
查看来源状态
查看当前素材是演示回放还是真实接口记录，以及最近资料时间。更新失败时仍保留之前的资料。

关注与视觉偏好保存在当前浏览器。这里的关注是方便再次找到议题的收藏功能，本版没有消息推送。

04

我的经历

这是你的贡献档案：关心“我写了什么、放在哪里、现在是什么状态”。

记录里有什么

  • 亲身经历：你遇到的情境、行动与结果。
  • 评论与回复：针对问题的补充、疑问或回应。
  • 补充来源：参考链接和你对其作用的说明。
  • 每份记录保留所属议题、公开身份、时间及状态。

在这里可以做什么

  • 按贡献类型筛选，输入关键词查找自己的记录。
  • 查看跨议题的贡献及它与当前条件的整理关联。
  • 打开贡献详情，核对理由、依据，必要时重新整理。
  • 新增贡献；在自己的详情中撤回公开展示或删除正文。
与小本子的区别：左侧是本人的档案与统计，右侧是编号贡献日志，按“我提供的材料”组织。它不负责批准其他人的问题或修改公共答案。点“我参与的问题”或记录的所属议题，才会前往答案广场。
05

看山的小本子

这是研究与审阅的工作台：关心“还有什么没弄明白、下一步该核对什么”。

待验证的条件
用“待验证”筛选查看“这几处，还想弄明白”的条件便签。点“查看已有依据”打开该条件的资料；点“为这个议题补充经历”打开对应议题的贡献表，之后再由看山整理关联。
下一问
看山提出的具体追问，包括提问理由、依据和状态。维护者可核对正文，再决定发出、暂缓或不采纳。
修订建议 维护者
查看建议新增、修改或移除哪些内容，核对引用，再决定是否更新公共答案。
答案成长与来源
按已保存的版本回看研究进展；打开来源，检查资料支持什么、还有哪些限制。
待确认 / 待审阅需要再核对稍后再看已发出 / 已采纳未采纳

暖色纸张、打孔笔记和深蓝进展摘要，让它与个人贡献日志形成清楚区别。使用“待验证”“下一问”“答案成长”等记录筛选及搜索定位问题；维护者另可筛选“待我审阅”。待审建议只是在等待人的判断，“稍后再看”和“不采纳”都会保留当前答案。

06

贡献、公开预览与隐私

先让你确认要公开的内容，再交给看山整理。

新增贡献 → 选择类型与身份 → 检查公开预览 → 勾选确认 → 保存并整理

三种公开身份

昵称：使用当前账号显示名称。
匿名：公开显示“匿名知友”。
化名：为这次贡献填写一个 2–24 字的名字。

公开身份按每次贡献选择，不需要为了换署名退出账号。

隐私检查的边界

系统会尝试隐藏常见手机号、邮箱和身份证号，并提示检测结果。它不能保证识别所有隐私信息。

姓名、地址、学校、工作单位、具体情境等仍需要你自行检查。公开前可以返回修改。

整理没完成
贡献已保存，页面显示当前整理状态或错误；作者和维护者可点“请看山再整理一次”。正在处理时可检查状态。
补充来源
选择“补充来源”，填写公开 HTTPS 链接和说明。系统保存引用，标注“贡献者提供 · 待核对”，不代表已验证链接内容。
撤回公开展示
自己的贡献详情 → “管理这份贡献” → 勾选确认 → “撤回公开展示”。公开正文和相关整理关联被隐藏。
删除经历正文
同一管理入口可进一步删除保存的原始正文。系统保留最小操作记录；引用这份贡献的历史内容会标记来源不可用。
已经撤回或删除的演示样例不会在刷新后自动补回。本版不提供已提交正文的直接编辑入口；提交之前，请利用公开预览认真检查。
07

下一问与后续回复

把“尚不知道”变成能被具体经历回答的问题。

先审阅，再发出 维护者

广场“看山的下一问”或小本子对应记录 → 查看提问理由、待验证条件和依据 → 编辑正文与公开身份 → “预览后再决定” → 勾选确认并发出。也可以展开“暂时不发出这条问题”，选择稍后再看或不采纳。

收到问题，实际写一条回复 登录用户

广场“下一问与后续回复” → 找到已送达的问题 → “回答这条下一问” → 输入具体回复 → 检查公开预览并保存。回复会保留它回应的问题，在该问题下展示，也进入自己的贡献记录。

状态可以追踪：问题有排队、发送和送达等状态。可重试的失败会提供维护者重试入口；结果不确定时先核对，避免重复发送。回复成为新证据后，仍需进入修订审核，才能影响公共答案。
08

修订、依据与版本历史

答案怎么变、为什么变、由谁确认，都有来处。

第一步：选择这次要用的证据 维护者

在广场点“看看依据”，或从小本子进入对应议题的来源。阅读摘要、作者和来源状态，勾选“用于修订”，再点击“根据选中的 N 份证据提出修订”。

第二步：逐条核对修改建议 维护者

打开待审修订，逐项比较“原来”和“建议改为”，查看新增、修改或移除的理由及引用。必要时展开新版本全文。核对后勾选确认，可填写审阅备注，再采纳、暂缓或不采纳。

需要重新核对时，不强行发布：如果建议基于旧答案，或引用资料已经不可用，采纳可能被阻止。回到当前版本与来源核对，再重新生成修订。

第三步：新版本发布，旧版本保留

采纳后，公共答案更新为新版本；从版本号、广场“答案成长记”或本子中的版本记录，可以回看各版全文、条件、贡献署名、审阅人和时间。点击历史条件还能追溯其依据。

09

从知乎线索，创建新议题

先寻找值得继续讨论的材料，再由人决定问题怎么问。维护者

广场“种下一个新问题” → 搜索 / 看当前热点 → 选择来源 → 编辑问题与类型 → 创建

新问题需要材料

至少选择一条候选来源，填写具体、开放的问题，选择“学习与成长”或“社会观察”。创建后进入该议题，继续收集经历、整理依据与答案。

已有问题也可以补线索

在来源面板输入搜索词，点“更新搜索来源”。系统保存新增资料、跳过重复项；失败时保留之前取得的内容。

查询失败时会保留上次结果、已选线索和问题草稿，并明确提示上次查询；“重试这次查询”继续失败的那次请求。演示身份的搜索和热点始终使用本地回放。

右上角身份 → “退出当前身份”。刷新仍使用有效的当前会话；退出后重新进入演示会创建新空间，不会自动找回之前那一轮体验。

为什么会看到四份并不是我亲自写的记录？

它们是首次进入个人页时添加的演示样例，用于体验经历、评论与来源的完整流程，正文明确标注“演示样例 · 虚构情境”。之后你新增的贡献会与这些样例一起出现在当前空间。

小本子里的建议，为什么还没出现在公共答案里？

建议要经过维护者核对和确认。它可能尚未审阅、被暂缓或不采纳；材料过期或依据不可用时，还需要重新核对。只有采纳修订才会发布新版本。

这是一个聊天机器人吗？
